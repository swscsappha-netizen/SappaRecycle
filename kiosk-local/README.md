# ตู้แบบติดตั้งใน Raspberry Pi

ชุดนี้ยังต้องติดตั้งและลงทะเบียนบน Raspberry Pi จริง ไม่ใช้หน้าตู้ออนไลน์เพื่อเปิดโหมด local

## เตรียมเครื่อง

ใช้ Raspberry Pi OS 64-bit และ Node.js 24 ขึ้นไป (มี `node:sqlite`) วางโปรเจกต์ที่ `/opt/sappa` แล้วรัน:

```sh
cd /opt/sappa/kiosk-local
npm run setup
```

setup สร้าง `data/device.json` ซึ่งเป็นความลับเฉพาะเครื่อง ห้ามส่งขึ้น Git หรือใส่ในหน้าเว็บ และสร้าง `data/register-device.sql` ที่มีเฉพาะแฮชสำหรับลงทะเบียน

## ลงทะเบียนเครื่องกับฐานข้อมูล

ผู้ดูแลรัน `supabase/kiosk-device.sql` ใน Supabase SQL Editor จากนั้นรัน `kiosk-local/data/register-device.sql` ที่สร้างบน Pi ใช้เจ้าหน้าที่ 32650 เป็นผู้รับผิดชอบการส่งแต้ม เจ้าหน้าที่ต้องมี is_council_member และ LINE binding ในฐานข้อมูลอยู่แล้ว แต่ไม่ต้องล็อกอินหน้าตู้

## เปิดใช้งาน

```sh
cd /opt/sappa/kiosk-local
npm start
```

เปิด Chromium ที่ `http://127.0.0.1:5056` หน้าตู้จะไม่ถาม LINE นักเรียนกรอกรหัส ตรวจชื่อ และกดยืนยันก่อนหยอด เชื่อมต่ออุปกรณ์ serial ผ่านปุ่มเชื่อมต่ออุปกรณ์

เมื่อออนไลน์ เครื่องโหลดข้อมูลนักเรียนและเก็บแคช ส่วนเมื่อออฟไลน์ใช้งานได้เฉพาะนักเรียนที่เคยมีข้อมูลในแคช ไม่มีการสร้างยอดแต้มเริ่มต้นจากข้อมูลตัวอย่าง รายการหยอดเก็บใน SQLite ก่อนส่ง คิว retry ทุก 15 วินาทีและใช้ receipt UUID เดิมเพื่อป้องกันเพิ่มแต้มซ้ำ ยอดที่ยังรอส่งแสดงแยกจากยอดล่าสุดบนเว็บ

สำรองโฟลเดอร์ data หลังหยุดบริการก่อนทุกครั้ง ห้ามลบฐานข้อมูลหรือ device.json ขณะที่มีรายการรอส่ง เครื่องรับ HTTP เฉพาะ loopback และตรวจ Host/Origin เพื่อกันคำสั่งจากเว็บไซต์อื่น

## เปิดบริการเมื่อบูต

แก้ User ใน `sappa-kiosk.service` ให้ตรงกับบัญชีจริงบน Pi และตรวจว่า `/usr/bin/node` เป็น Node 24 จากนั้น:

```sh
sudo cp sappa-kiosk.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now sappa-kiosk
```

ตั้ง desktop autostart ให้เปิด `chromium --kiosk http://127.0.0.1:5056` ตามชื่อ executable ของ Chromium ในเครื่อง

## ต้องทดสอบที่ตู้จริง

ทดสอบออนไลน์ → ปิดเน็ต → หยอดและจบรายการ → ปิดเปิดบริการ → เปิดเน็ต ตรวจยอดบนเว็บเพิ่มเพียงครั้งเดียว รวมถึงทดสอบเซนเซอร์จริง ยังไม่ได้ติดตั้งบน Pi หรือยืนยันการส่งแต้มจาก Pi จนกว่าจะทำขั้นตอนนี้
