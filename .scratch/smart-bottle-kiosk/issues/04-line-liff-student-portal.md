# 04: LINE LIFF Student Portal & Profile Management

**What to build:**
Create the mobile-optimized LINE LIFF Web Application for students:
- LINE LIFF SDK initialization and identity authentication.
- First-time onboarding: binding LINE Account (`line_user_id`) to a 5-digit student ID.
- Student Dashboard displaying student profile (Name, Room, Student ID), current points balance, total bottles recycled, and quick action cards.
- Profile settings allowing students to view and edit their 10-digit mobile phone number (ADR-0001).
