# Sappha Recycle - Project Glossary & Technical Terminology

| คำศัพท์ (Term) | ความหมายและหน้าที่ในระบบ (Definition & Function) |
| :--- | :--- |
| **Sappha Recycle** | โครงงานและเว็บไซต์ตู้รับคืนและคัดแยกขวดพลาสติก PET และกระป๋องอะลูมิเนียม CAN อัจฉริยะ โรงเรียนสรรพวิทยาคม (รีแบรนด์จาก SappaRecycle ตาม ADR-0025) |
| **Kiosk Touchscreen UI** | ส่วนติดต่อผู้ใช้งานบนหน้าจอสัมผัส Raspberry Pi 4 (1024x600 px) สำหรับให้นักเรียนกรอกรหัสและดูสถานะการหยอดขวด |
| **LINE LIFF** | LINE Front-end Framework สำหรับให้นักเรียนดูแต้มสะสม แลกคูปองของรางวัล และสภานักเรียนสแกนตรวจสอบ |
| **Sensor Fusion** | อัลกอริทึมการผสมผสานสัญญาณระหว่างกล้อง AI Vision, เซนเซอร์โลหะ (Inductive Proximity Sensor) และเซนเซอร์อินฟราเรด (IR Sensor) เพื่อตัดสินใจแยกขวด/กระป๋องอย่างแม่นยำ 100% |
| **Web Audio API Sound Engine** | ระบบสังเคราะห์เสียงดิจิทัลผ่านเบราว์เซอร์ ทำงานได้ 100% แบบออฟไลน์บน Raspberry Pi 4 ให้เสียง Beep, เหรียญเด้ง Chime, และเสียงเฉลิมฉลอง Fanfare |
| **WebSerial API** | มาตรฐานการเชื่อมต่อพอร์ต USB Serial ตรงระหว่างเบราว์เซอร์ Chromium กับบอร์ดไมโครคอนโทรลเลอร์ (Arduino/ESP32) ที่ความเร็ว 115200 Baud |
| **ADR (Architectural Decision Record)** | เอกสารบันทึกการตัดสินใจทางสถาปัตยกรรมซอฟต์แวร์และฮาร์ดแวร์ของระบบ |
| **Sole Super Admin** | สิทธิ์แอดมินสูงสุดสำหรับนักเรียนรหัส `32650` (นายสุวรรณวัฒน์ ก้องเวหา) เพื่อจัดการระบบหลังบ้าน `admin.html` |
| **Student Council Scanner** | สิทธิ์สแกนเนอร์สำหรับคณะกรรมการสภานักเรียนทั้ง 27 คนเพื่อสแกนตัดจ่ายคูปองของรางวัล |
| **Ultrasonic Bin Full Sensing** | การตรวจวัดระดับความจุถังขยะ PET/CAN ด้วยคลื่นเสียงอัลตราโซนิก เพื่อระงับการทำงานเมื่อความจุ $\ge 90\%$ (ADR-0023) |
| **Automated LINE Maintenance Alert** | การยิงข้อความแจ้งเตือนอัตโนมัติเข้ากลุ่ม LINE สภานักเรียนเมื่อถังขยะเต็มหรือเกิดข้อผิดพลาดสายพานติดขัด (ADR-0023) |
| **Council Maintenance PIN Unlock** | ระบบปลดล็อกและรีเซ็ตถังขยะด้วยรหัส PIN สภานักเรียน (`32650` หรือ `99999`) บนหน้าจอสัมผัส (ADR-0023) |
| **Production Kiosk Mode** | โหมดการทำงานจริงของหน้าจอตู้คีออส โดยถอดแผงควบคุมจำลอง (Hardware Controller Dock) ออกทั้งหมด และรับสัญญาณจากเซนเซอร์ฮาร์ดแวร์จริงผ่าน WebSerial / GPIO และฐานข้อมูลนักเรียนจริง 2,906 คน (ADR-0024) |
