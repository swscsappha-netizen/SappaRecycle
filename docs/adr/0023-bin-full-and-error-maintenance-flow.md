# ADR 0023: ระบบตรวจจับขวดเต็มถังและแจ้งเตือนข้อผิดพลาดตู้ขัดข้องอัตโนมัติ (Bin Full Capacity & Hardware Error Maintenance Flow)

## สถานะ (Status)
**ยอมรับแล้ว (Accepted)** — 30 สิงหาคม 2569

## บริบท (Context)
ตู้รับขวดรีไซเคิลอัจฉริยะ (SappaRecycle Kiosk) ติดตั้งอยู่ภายในโรงเรียนสรรพวิทยาคม เพื่อรองรับการหยอดขวดพลาสติกใส PET และกระป๋องอะลูมิเนียม CAN จากนักเรียนจำนวน 2,906 คน หากไม่มีระบบตรวจจับความจุถังขยะและข้อผิดพลาดของฮาร์ดแวร์ อาจเกิดปัญหาขยะล้นถัง (Overflow), ขยะติดขัดในสายพาน (Conveyor Jam), หรือระบบเซนเซอร์ขัดข้อง ส่งผลให้เครื่องเสียหายและนักเรียนเสียคะแนน

## การตัดสินใจ (Decision)

### 1. การตรวจวัดความจุด้วยเซนเซอร์อัลตราโซนิก (Dual Ultrasonic Bin Capacity Sensing)
* ตู้ Kiosk ติดตั้งเซนเซอร์วัดระยะอัลตราโซนิก 2 จุด:
  1. **ถังขวดพลาสติก PET:** ตรวจสอบความจุจากระยะห่างผิวด้านบนของกองขวด
  2. **ถังกระป๋องอะลูมิเนียม CAN:** ตรวจสอบความจุของถังโลหะ
* **เกณฑ์การตัดการทำงาน (Thresholds):**
  * `0% - 79%`: ระดับปกติ (Normal Operation) — ไฟสถานะสีเขียว
  * `80% - 89%`: ระดับเตือนใกล้เต็ม (Warning Level) — ไฟสถานะสีส้ม
  * `≥ 90%`: ระดับเต็มความจุ (Bin Full Lockout) — ไฟสถานะสีแดง ระงับการรับขยะชั่วคราว

### 2. หน้าจอล็อกระบบแบบสมบูรณ์ (Complete Touch Screen Lockout)
* เมื่อเซนเซอร์ตรวจพบว่าถังเต็ม (`≥ 90%`) หรือสายพานติดขัด:
  1. หน้าจอจะตัดเข้าสู่สถานะ **ล็อกหน้าจอแบบสมบูรณ์ (Complete Lockout)** โดย **ไม่แสดงปุ่มใดๆ ที่สามารถกดได้บนหน้าจอ** (ไม่มีปุ่มกลับหน้าแรก, ไม่มีปุ่มแจ้งเตือน, ไม่มีปุ่มปลดล็อก)
  2. แสดงเฉพาะข้อความและไอคอนแจ้งเตือนที่ชัดเจน:
     * **หัวข้อ:** `ถังขยะเต็ม` หรือ `เกิดข้อผิดพลาด / สายพานติดขัด`
     * **ข้อความ:** `โปรดติดต่อคณะกรรมการสภานักเรียน`
     * **คำอธิบาย:** `ตู้ระงับการรับขวดและกระป๋องชั่วคราว ขออภัยในความไม่สะดวกครับ 🌿`
  3. ป้องกันไม่ให้นักเรียนกดข้ามขั้นตอน หรือหยอดขยะซ้ำจนเกิดความเสียหายต่อเครื่อง
  4. การปลดล็อกจะเกิดขึ้นอัตโนมัติเมื่อเจ้าหน้าที่นำขยะออกจากถังและเซนเซอร์ตรวจพบว่าความจุลดลง หรือปลดล็อกผ่านระบบแอดมินหลังบ้าน (`admin.html`)

### 3. การส่งแจ้งเตือนอัตโนมัติเข้า LINE สภาฯ (Automated LINE Maintenance Alert)
* มีปุ่มให้นักเรียนหรือระบบส่งแจ้งเตือนอัตโนมัติเข้ากลุ่ม LINE คณะกรรมการสภาฯ ทันที:
  * ระบุหมายเลขตู้ (Kiosk ID) และจุดติดตั้ง
  * ระบุประเภทถังที่เต็ม หรือรหัสข้อผิดพลาด
  * ระบุเวลาเกิดเหตุ (Timestamp) เพื่อให้เจ้าหน้าที่มาเทขยะและรีเซ็ตตู้ได้ทันที

### 4. การปลดล็อกและรีเซ็ตตู้ด้วยรหัส PIN สภาฯ (Council PIN Unlock & Reset Flow)
* คณะกรรมการสภาฯ หรือผู้ดูแลตู้ (เช่น นายสุวรรณวัฒน์ ก้องเวหา รหัส `32650` หรือ Master PIN `99999`) สามารถแตะปุ่ม **"ปลดล็อกตู้ (สำหรับเจ้าหน้าที่)"**
* ป้อนรหัส PIN 5 หลักบนหน้าจอสัมผัส:
  * ระบบจะรีเซ็ตค่าระดับความจุกลับเป็น `0%`
  * บันทึก Log การเปิดตู้และเวลาเทขยะลงฐานข้อมูล Cloud Supabase
  * ตู้จะกลับสู่หน้าแรก (Welcome Screen) พร้อมให้บริการนักเรียนทันที

## ผลกระทบ (Consequences)
* **ข้อดี:**
  * ป้องกันขยะล้นถังและสายพานติดขัดได้อย่างมีประสิทธิภาพ 100%
  * สภาฯ ได้รับการแจ้งเตือนทาง LINE ทันที ไม่ต้องเดินมาตรวจเช็คตู้ตลอดเวลา
  * การกู้คืนทำได้สะดวกรวดเร็วผ่านรหัส PIN บนหน้าจอสัมผัส
* **การดูแลรักษา:**
  * เซนเซอร์อัลตราโซนิกต้องได้รับการทำความสะอาดฝุ่นเป็นประจำทุกสัปดาห์
