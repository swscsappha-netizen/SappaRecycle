# ADR 0024: การปรับเข้าสู่ Production Kiosk Mode และถอดแถบจำลองฮาร์ดแวร์ (Simulation Dock Removal)

## สถานะ (Status)
**อนุมัติและบังคับใช้ (Approved & Implemented)** — 30 สิงหาคม 2569

---

## บริบท (Context)
ในระหว่างขั้นตอนการพัฒนาและทดสอบส่วนติดต่อผู้ใช้งาน (Kiosk UI) บนเครื่องคอมพิวเตอร์ ระบบได้ติดตั้งคอมโพเนนต์ `HardwareControllerDock` ไว้ด้านล่างของหน้าจอ เพื่อจำลองการสลับหน้าจอ (Welcome, Numpad, Modal Phone, Deposit, Summary, Bin Full) และจำลองการยิงสัญญาณ GPIO จากเซนเซอร์ตรวจจับขวด PET, กระป๋อง CAN, ขยะแปลกปลอม ตลอดจนจำลองระดับความจุถังขยะ $95\%$

เมื่อการออกแบบและทดสอบระบบ UI/UX เสร็จสมบูรณ์แล้ว ผู้ใช้งานได้สั่งการให้นำระบบจำลองออกทั้งหมด (`/grill-with-docs โอเคแล้วเอาระบบจำลองออกทั้งหมดเลย ใช้ข้อมูลจริง`) เพื่อให้ระบบเข้าสู่ **โหมดการใช้งานจริง (Production Kiosk Mode)** บนหน้าจอสัมผัส Raspberry Pi 4 อย่างเต็มรูปแบบ 100%

---

## การตัดสินใจทางสถาปัตยกรรม (Architectural Decisions)

### 1. ถอดคอมโพเนนต์จำลอง `HardwareControllerDock` ออกทั้งหมด
* นำ `<HardwareControllerDock ... />` ออกจาก `App.tsx`
* หน้าจอ UI จะแสดงผลแบบ Full Screen Viewport (1024x600 px) สวยงาม สะอาดตา ไม่มีแถบหรือปุ่มจำลองใดๆ มารบกวนผู้ใช้งานจริง

### 2. การเชื่อมต่อข้อมูลจริง 100% (Production Data Integration)
* **ฐานข้อมูลนักเรียนจริง 2,906 คน:** เชื่อมต่อกับ Supabase Cloud (`students` table) พร้อมข้อมูลสำรอง Local Roster รองรับการค้นหารหัสนักเรียน 5 หลักแบบ Real-time
* **การบันทึกแต้มและประวัติการหยอดจริง:** เมื่อหยอดขวดเสร็จสิ้น ระบบจะเรียกใช้ PostgreSQL RPC `credit_recycle_batch` เพื่ออัปเดตแต้ม (`current_points`) และจำนวนขวด (`total_bottles_recycled`) ของนักเรียนลงฐานข้อมูลจริงทันที
* **การรับสัญญาณฮาร์ดแวร์จริง:** ระบบรับข้อมูลการหยอดขวด/กระป๋องจากเซนเซอร์จริงของ Raspberry Pi 4 ผ่าน `SerialHardwareManager` (WebSerial API @ 115200 Baud) หรือ GPIO Daemon

---

## ผลกระทบ (Consequences)

### ข้อดี (Positive Impact)
1. **ความปลอดภัยและความสะอาดตา:** ไม่มีปุ่มจำลองที่นักเรียนอาจเผลอไปกดเปลี่ยนหน้าจอได้เอง
2. **ความพร้อมสำหรับการติดตั้งจริง:** ตู้พร้อมสำหรับการติดตั้งใช้งานจริงในโรงเรียนสรรพวิทยาคมทันที
3. **ประสิทธิภาพการทำงานสูงสุด:** ลด Bundle Size และภาระการเรนเดอร์ของเบราว์เซอร์บน Raspberry Pi 4
